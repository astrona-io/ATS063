# Introduction

Before you start the first module, take ten minutes for this introduction. It tells you what this course trains you to do, how to get your machine ready, and who builds the course. You do not touch a cluster here, but these three short pages make every page after them easier to follow.

The introduction has three pages. **Welcome To The Course** explains who the course is for, what you can do at the end, how the course is laid out and how to read a page. **Get Your Machine Ready** lists the tools you need and the `astrona` commands you use every day. **How This Course Is Made** explains how the content is written and checked, who maintains it and how to report a mistake.

When you are done, the course starts with the Argo Events flow: how an event enters the cluster, how it is stored and how it starts work.
