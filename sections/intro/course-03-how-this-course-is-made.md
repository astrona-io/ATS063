# How This Course Is Made

The authors map every section to the official Certified Argo Project Associate (CAPA) objectives for Argo Events and check each mechanism against the upstream documentation and source code of Argo Events 1.9.6. They write examples that show the responsible component and a realistic failure.

Pages are written in plain English with the real technical terms. A page never shows output that the author did not see or that can change from run to run.

## Checks

Structural checks verify the reading order, the closing summaries, the lab configuration, the shell scripts and the YAML files. These are static checks. A run of the labs and playgrounds on a cluster is recorded separately, and until then the labs are marked untested.

## Who maintains it

The contributors on GitHub maintain the material. To report a mistake, open an issue and name the page and the statement that is wrong. The license of the repository governs reuse.

Objectives belong to their respective owners. The reading and the knowledge checks are original practice material and not official exam questions. The names in the examples, such as `starfleet` and `outpost`, are illustrative and have no technical meaning.
